# Security and release boundary

This public repository contains product documentation and a conceptual architecture graphic only. It excludes the original application source, financial records, SQLite databases, API keys, deployment credentials, Expo EAS identifiers and signing materials.

The supplied source was reviewed for structure and selected sensitive patterns. This is not an independent security audit or penetration test.

The LICENSE text in the supplied original source is an Expo/650 Industries MIT license, not evidence that the Hesabdar Man application is released under MIT. It has not been presented as this project's license.

For security concerns, contact [NaarCode](https://naarcode.com/fa) privately.

## Published code excerpt

The repository also includes a small standalone example derived from non-sensitive source and a synthetic-input test. This does not include production deployment code, credentials, customer data or the full application. The excerpt should not be treated as a comprehensive security review.
