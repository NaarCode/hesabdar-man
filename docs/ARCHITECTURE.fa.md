# معماری فنی

پروژه با React Native و Expo توسعه داده شده است. React Navigation ناوبری را مدیریت می‌کند و رابط کاربری برای زبان فارسی و چیدمان راست‌به‌چپ طراحی شده است. Zustand برای مدیریت وضعیت برنامه استفاده می‌شود. لایه ذخیره‌سازی شامل expo-sqlite، طرح داده و مهاجرت‌ها، سرویس داده و کوئری‌های تفکیک‌شده بر اساس حوزه است.

## بخش‌های موجود در سورس

حساب‌ها و گزارش هر حساب، تراکنش‌ها و انتقال وجه، دسته‌بندی‌ها، بودجه، گزارش‌های مالی، فهرست و اقلام خرید، ابزارهای تاریخ جلالی و ذخیره محلی فایل رسید.

## جریان داده

۱. کاربر در صفحه یا کامپوننت عملیاتی انجام می‌دهد.

۲. وضعیت برنامه و سرویس مرتبط، عملیات را مدیریت می‌کنند.

۳. کوئری‌ها داده‌ها را در SQLite می‌خوانند یا تغییر می‌دهند.

۴. صفحه نتیجه را نمایش می‌دهد.

این توضیح یک نمای مفهومی است و جزئیات خصوصی دیتابیس و منطق برنامه را فاش نمی‌کند.

## محدوده توسعه

پروژه هنوز در حال تکمیل است. در نسخه بررسی‌شده، توابع فایل src/utils/notifications.js هنوز زمان‌بندی اعلان‌ها را انجام نمی‌دهند؛ بنابراین قابلیت یادآوری فعال در این ویترین ادعا نشده است. این بررسی، ممیزی کامل امنیت یا صحت عملکرد برنامه نیست.
